# Đám cưới Thịnh & Thư

Website thiệp cưới online của Quang Thịnh & Ngọc Thư.

## Tính năng

- Thiệp cưới online với hiệu ứng đẹp (confetti, animation, nhạc nền)
- Thư viện ảnh kỷ niệm 2019-2024 và ảnh cưới
- Gửi lời chúc và xác nhận tham dự
- Hộp mừng cưới (QR code ngân hàng)
- Dashboard quản trị (đăng nhập bằng mật khẩu)
- Chế độ sáng/tối

## Công nghệ

- HTML / CSS / JavaScript (Vanilla)
- [Bootstrap 5.3](https://getbootstrap.com/)
- [JSONBin.io](https://jsonbin.io/) (Database miễn phí)
- [AOS](https://michalsnik.github.io/aos/) (Scroll Animation)
- [Canvas Confetti](https://www.kirilv.com/canvas-confetti/)
